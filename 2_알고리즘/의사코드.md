# 2. 알고리즘 (의사 코드) (10점)

## 1. 프로젝트 전체 작동 로직
```
시작
    랜덤 초기화 (시간 기반)
    게임판 초기화 (9칸을 모두 빈칸으로)
    
    선공/후공 선택 입력받기 (1: 플레이어, 2: AI)
    
    게임판 출력
    
    반복 (승자가 나올 때까지):
        만약 플레이어 차례이면:
            사용자로부터 위치 입력 (1~9)
            만약 입력이 유효하지 않으면:
                "잘못된 위치" 메시지 출력
                다시 입력받기
            아니면:
                해당 위치에 'O' 표시
        아니면 (AI 차례):
            AI 수 계산 함수 호출
            해당 위치에 'X' 표시
            AI가 둔 위치 출력
        
        게임판 출력
        
        승자 확인 함수 호출
        만약 승자가 있으면:
            결과 출력 (플레이어 승리 / AI 승리 / 무승부)
            반복 종료
        
        차례 바꾸기 (플레이어 ↔ AI)
    반복 끝
    
    종료 메시지 출력
종료
```

## 2. 핵심 기능 1: AI 수 선택 함수
```
시작
    입력: AI가 선공인지 여부
    
    // 규칙 1: 이길 수 있으면 이긴다
    이길 수 있는 위치 찾기 ('X'로)
    만약 찾았으면:
        그 위치 반환
    
    // 규칙 2: 상대의 승리를 막는다
    상대가 이길 수 있는 위치 찾기 ('O'로)
    만약 찾았으면:
        그 위치 반환
    
    // 규칙 3: 선공일 때는 중앙을 잡는다
    만약 AI가 선공이고 중앙(5번)이 비어있으면:
        중앙 위치 반환
    
    // 규칙 4: 빈 칸에 랜덤으로 둔다
    랜덤으로 빈 칸 찾기 함수 호출
    그 위치 반환
종료
```

## 3. 핵심 기능 2: 이길 수 있는 위치 찾기 함수
```
시작
    입력: 찾을 플레이어 ('X' 또는 'O')
    
    승리 조합 8가지 정의:
        - 가로 3줄 (0-1-2, 3-4-5, 6-7-8)
        - 세로 3줄 (0-3-6, 1-4-7, 2-5-8)
        - 대각선 2줄 (0-4-8, 2-4-6)
    
    반복 (각 승리 조합에 대해):
        플레이어 말 개수 = 0
        빈 칸 위치 = -1
        
        반복 (해당 조합의 3칸에 대해):
            만약 현재 칸이 플레이어 말이면:
                플레이어 말 개수 증가
            아니면 만약 현재 칸이 비어있으면:
                빈 칸 위치 저장
        반복 끝
        
        만약 플레이어 말 개수가 2이고 빈 칸이 1개이면:
            빈 칸 위치 반환
    반복 끝
    
    찾지 못했으면 -1 반환
종료
```

## 4. 핵심 기능 3: 승자 확인 함수
```
시작
    승리 조합 8가지 정의:
        - 가로 3줄 (0-1-2, 3-4-5, 6-7-8)
        - 세로 3줄 (0-3-6, 1-4-7, 2-5-8)
        - 대각선 2줄 (0-4-8, 2-4-6)
    
    반복 (각 승리 조합에 대해):
        조합의 3칸 위치를 a, b, c로 저장
        
        만약 a칸이 비어있지 않고 a == b == c 이면:
            a칸의 말 ('O' 또는 'X') 반환
    반복 끝
    
    // 무승부 확인
    반복 (게임판의 모든 칸에 대해):
        만약 빈 칸이 있으면:
            ' ' (게임 진행 중) 반환
    반복 끝
    
    'D' (무승부) 반환
종료
```

## 5. 보조 기능 1: 랜덤 빈 칸 선택 함수
```
시작
    빈 칸 목록 배열 생성
    빈 칸 개수 = 0
    
    반복 (게임판의 모든 칸에 대해):
        만약 현재 칸이 비어있으면:
            빈 칸 목록에 추가
            빈 칸 개수 증가
    반복 끝
    
    만약 빈 칸이 없으면:
        -1 반환
    
    랜덤으로 빈 칸 하나 선택
    선택된 위치 반환
종료
```

```
시작
    빈 줄 출력

        "      7 8 9"
```
