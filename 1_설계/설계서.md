# 1. 프로그램 설계서 (5점)

## 1. 프로젝트 주제
규칙 기반 에이전트 - 틱택토

## 2. 핵심 기능 목록
1. 3 x 3 판에서 플레이어와 프로그램이 O와 X를 번갈아 둔다
2. 플레이어가 두는 수에 따라 규칙에 맞춰 배열한다.
3. 규칙은 다음과 같다.

규칙
1. 이길 수 있으면 이긴다
보드에 자신(X)의 2개와 빈칸 하나가 있으면 그 칸에 둔다.
2. 상대의 승리를 막는다
보드에 상대(O)의 2개와 빈칸 하나가 있으면 그 칸에 둔다.
3. 선공일 때는 반드시 중앙을 잡는다
4. 빈 칸에 수를 둔다.


## 3. 데이터 구조 설계
(프로그램에 필요한 핵심 변수, 배열을 설계하세요. 필요하면 구조체(struct)를 사용할 수도 있습니다.)

// findWin 함수 내부 데이터
